# Week 08 — Arduino Basics

---

### Activities

| Activity | What I Made                   |
| -------- | ----------------------------- |
| `8a`     | Explored basic Arduino wiring and experimented with inputs and outputs and LED to create simple interactions. |
| `8b`     | Tested a phototransistor, a force sensor, and an ultrasonic sensor to measure light, pressure, and distance. |

---

### This Week

I explored Arduino as an introduction to physical computing. I learned basic wiring and how to connect components to build simple circuits. By experimenting with a phototransistor, a force sensor, and an ultrasonic sensor, I learned how physical inputs can be read as data and used to create interactions.
